# PvZ 좀비 이동 분석 실행 안내

이 안내는 REA를 이용한 첫 분석 세션부터 조작 시제품의 검증까지 사용한다. 아직 실제 함수 주소나 객체 오프셋은 확인되지 않았다.

## 환경 준비

2026-10-14에 확인한 [공식 설치 안내](https://rea.tools/get-started/)는 Node.js 22.19 이상인 22 계열, 24.11 이상인 24 계열 또는 26 이상, Ghidra 12.1.x, 64비트 JDK 21 이상을 안내한다. 설치 시 최신 지원 조건을 다시 확인하고 실제 설치 버전을 기록한다.

Windows Ghidra 경로는 로컬 고정 NTFS 드라이브의 x86/x64 PE 실행 파일에 대한 실험적 읽기 전용 지원이다. 아래는 준비 후 수동 실행할 명령이며, 이 계획 작성 과정에서 실행하지 않았다.

```powershell
node --version
npm.cmd --version

# 실제 설치 위치로 바꾼다.
$env:GHIDRA_INSTALL_DIR = "C:/tools/ghidra_12.1.4_PUBLIC"
$env:JAVA_HOME = "C:/tools/jdk-21"

npx.cmd -y rea-agents@latest doctor --provider ghidra --json
npx.cmd rea-agents@latest setup
```

setup에서 사용할 에이전트를 선택하고 변경 계획을 확인한다. 설정 완료 후 클라이언트를 재시작한다. 재현성을 위해 설치된 REA 패키지 버전을 기록하고 이후 실행에서는 해당 버전을 고정한다. 진단 실패 시 오류를 해결한 뒤 바이너리 분석으로 넘어간다.

## 대상 기록

| 항목 | 값 |
| --- | --- |
| 판본 및 구매 경로 | 미확인 |
| 실행 파일 버전 | 미확인 |
| SHA-256 | 미확인 |
| PE 아키텍처 | 미확인 |
| OS | 미확인 |
| REA / Ghidra / JDK / Node.js | 미확인 |
| 에이전트와 모델 | 미확인 |
| 실행 중 검증 도구 | 미선정 |

게임 경로는 로컬 기록으로 관리한다. 공개 문서에는 개인 경로를 남길 필요가 없다.

## 첫 요청

```text
REA로 다음 PvZ 실행 파일을 분석해줘.
대상: <실행 파일의 절대 경로>

목표는 기존 일반 좀비 한 마리의 자동 보행을 중지하고,
A/D 입력으로 가로 이동시키는 모드를 만드는 것이다.

먼저 파일의 버전 정보, PE 아키텍처와 SHA-256을 기록하고
Ghidra provider로 분석 가능한지 확인해줘.
좀비 생성, 보관, 순회 및 위치 갱신 코드의 단서를 조사해줘.

다른 판본의 주소를 가져다 적용하지 마.
확인된 사실과 가설을 구분하고 아직 패치를 수행하지 마.
바이너리가 분석되지 않으면 실패 지점과 진단 결과를 기록해줘.
```

## 이동 경로 추적 요청

```text
앞서 발견한 단서에서 좀비의 가로 위치를 갱신하는 함수를 추적해줘.

확인할 항목:
- 좀비 객체를 저장하고 순회하는 구조
- 위치와 이동 속도로 추정되는 필드
- 걷기, 공격, 죽음을 구분하는 상태 및 분기
- 위치를 쓰는 명령어와 해당 함수를 호출하는 경로
- 스테이지 종료 및 사망 시 객체 수명

함수 주소, 필드 오프셋, 데이터형 가설과 명령어 근거를 기록해줘.
네가 붙인 함수 이름은 추정 이름이라고 표시해줘.
실행 중 검증할 관찰 항목과 중단점 후보를 제시해줘.
디컴파일 결과만으로 확인되지 않는 부분은 미확인으로 남겨줘.
```

## 실행 중 검증

대상 아키텍처를 지원하는 디버거를 선정한다. 먼저 일반 좀비가 등장하는 상황에서 읽기와 관찰로 검증한다.

1. 화면에서 좀비를 하나 식별하고 추정 객체의 위치 변화와 대조한다.
2. 후보 명령어에 중단점을 두고 해당 객체의 좌표를 쓰는지 확인한다.
3. 걷기와 식물 접촉 시 정지 상황을 비교한다.
4. 피격과 사망 시 상태 변화 및 객체 제거를 확인한다.
5. 스테이지 재시작 후 객체 참조를 다시 구해야 하는지 확인한다.

이 결과가 확보된 뒤에만 대상 한 마리의 이동을 변경한다. 읽기 검증이 실패하면 모드 코드로 우회하지 말고 객체·오프셋·호출 경로 가설을 수정한다.

## 시제품 구현 요청

이 요청은 이동 경로와 객체 수명을 확인한 다음 사용한다.

```text
검증된 분석 결과를 바탕으로 일반 좀비 한 마리만 조작하는 시제품을 설계해줘.

- 검증한 바이너리 해시만 지원한다.
- 선택한 객체만 자동 보행을 중지하고 A/D 입력으로 가로 이동한다.
- 다른 좀비와 기존 피격 처리는 유지한다.
- 대상 사망, 스테이지 전환, 게임 종료 시 조작을 중지한다.
- 조작 해제 시 원래 동작을 복원한다.

후킹, 메모리 패치 등 적용 방식을 분석 근거로 선택해줘.
실행 스레드, 호출 규약, 객체 수명과 원복 절차를 설명한 뒤 구현해줘.
전체 이동 함수를 무조건 막거나 검증되지 않은 주소를 사용하지 마.
README의 검증 시나리오에 따라 결과를 기록해줘.
```
